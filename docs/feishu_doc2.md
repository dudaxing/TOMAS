## 1. 概述与目标

TOMAS 是**多尺度流体拓扑优化**框架：把宏观流道布局与微观多孔微结构统一到一个**可微**优化问题中，在满足接触面积（2D 即微结构周长之和）约束下，**最小化流体耗散功率**。三段式：

1. **离线均匀化**：用 super-shape（Gielis 曲线）参数化微结构，随机采样 7000 个，在 150×150 网格上做 Stokes/Brinkman 数值均匀化 → 2×2 渗透率张量 C、接触面积 Γ、体积分数 vf。
2. **VAE 训练**：把 12 维属性压成 2 维连续可微隐空间。
3. **多尺度优化**：坐标神经网络输出每个宏观单元的隐变量 (z₁,z₂) 与取向 θ → 解码器给出局部渗透率 → 组装 Taylor–Hood (Q2-Q1) 有限元 Stokes 方程求解流场 → PyTorch 自动微分做罚函数梯度优化。

**本轮目标**：在前几轮已端到端打通的基础上，定位并消除"复现设计图与论文图（Fig 10/11/16）的视觉差距"，做到视觉尽可能一致，并据此重写实现与理论文档。

## 2. 理论方案

### 2.1 低雷诺数流动：Stokes 方程与 Brinkman 罚

器件内为低雷诺数流动，由 **Stokes 方程**控制：

```
-μ ∇²u + ∇p = f,      ∇·u = 0
```

为在同一套有限元里同时表达"固体（不可流）"与"流体（自由流）"，引入 **Brinkman 罚项**，把固体建模为渗透率极低的多孔介质：

```
-μ ∇²u + α(x) u + ∇p = f
```

- α(x) 为逆渗透率：流体区 α=0，固体区 α=αₘₐₓ=1e6。α 很大时 α·u 主导，强制该处 u→0，从而"关闭"固体像素的流动。这把离散拓扑转为连续材料场，使梯度优化可行。

### 2.2 super-shape（Gielis）微结构参数化

微结构边界用 **Gielis 超公式**生成，极坐标下：

```
r(φ) = [ |cos(mφ/4)/a|^n2 + |sin(mφ/4)/b|^n3 ]^(−1/n1)
```

6 个核心参数 `{a, b, m, n1, n2, n3}`（外加中心 cx,cy）控制形状：
- **m**：旋转对称的"瓣数"。m=2 → 2 折（叶/透镜/椭圆）；m 大 → 多角星或近圆；**m<1 → 鱼/眼/不对称花瓣**（论文选出的 M\* 即 m≈0.6）。
- **n1,n2,n3**：边的凹凸/尖锐度。n<1 → 凹陷/尖角；n=2 → 椭圆；n>2 → 圆角方/近圆。
- **a,b**：两个半轴尺度（a≠b → 拉长 → 各向异性）。

**论文采样规格（Sec. 2.3）**：`0.05 ≤ a,b ≤ 0.75`、`1 ≤ m ≤ 22`、`0.5 ≤ n1,n2,n3 ≤ 10`，**均匀且独立**采样 7000 个。

> 关键认识：论文所依赖的"定向导流"叶/鱼形微结构（强各向异性）并不需要在数据中常见——它们由**解码器在隐空间外推/导航**得到（M\* 的 m=0.604 甚至落在采样区间 [1,22] 之外），优化器因其低耗散而选用之。

### 2.3 周期性数值均匀化 → 渗透率张量 C

单个微结构（周期单胞）的宏观等效渗透率由**渐近均匀化**得到：对单胞施加**周期边界**，分别加两个单位体力载荷 f=(1,0)、f=(0,1)，求解 Brinkman-Stokes 方程，单胞内速度的体积平均给出对角渗透率：

```
C00 = ⟨u0⟩,   C11 = ⟨v1⟩    (非对角项比对角项小 ~3 个数量级，可略)
```

取向通过张量旋转纳入：`C_trans = R(θ) · diag(C00,C11) · R(θ)ᵀ`。数值实现基于 Andreassen & Andreasen (2014)：4 节点双线性、压力稳定化单元，150×150 网格，固体 Brinkman 系数 1e6、流体 0。

### 2.4 变分自编码器（VAE）：可微设计空间

直接在离散、高维的 super-shape 属性空间上优化不可行。VAE 学习一个低维连续流形：
- **编码器** q(z|x)：12 维属性 → 2 维隐分布 (μ,σ)；
- **重参数化** z = μ + σ·ε, ε∼N(0,I)，使采样可微（GPU 反向传播的关键）；
- **解码器** p(x|z)：隐变量 → 重建 12 维属性（含 C00、C11）；
- **损失** = 重构 MSE + KL 散度（KL 拉向 N(0,I)，保证隐空间连续可插值）。

训练后，**解码器即一个可微的"隐变量 → 渗透率张量"材料插值模型**。

### 2.5 坐标神经网络 + Fourier 投影

设计变量不是逐单元密度，而是**坐标网络**权重：输入单元中心坐标 (x,y)，经 **Fourier 特征映射**（提升高频表达），过 2×20 LeakyReLU，输出该单元的 (z₁,z₂,θ)。z 约束于 [−3,3]，θ 经缩放约束。坐标网络隐式正则化设计场（相邻单元共享权重→空间平滑），并把设计维度与网格解耦。

### 2.6 多尺度拓扑优化问题

```
min_w   P(u) = 耗散功率 = ½ fᵀu
s.t.    K(C(w)) u = f          (Stokes-Brinkman 有限元状态方程, Taylor–Hood Q2-Q1)
        g(w) ≤ 0               (接触面积下限 / 体积分数 约束)
```

- 局部渗透率 C 由解码器从 (z₁,z₂) 得到，按 θ 旋转后填入全局刚度阵 K；逆渗透率 1/C00、1/C11 进入 Brinkman 项。
- 约束用**罚函数法**并随 epoch 逐步加重（continuation）；目标用首迭代值缩放。
- 状态方程求解与对 w 的梯度，全部由 PyTorch 自动微分 + 可微稀疏求解器 `torch_sparse_solve` 完成。

## 3. 实现过程

### 3.1 环境（WSL）

Windows 11 + WSL2 Ubuntu-22.04，32 核 / 62 GB / RTX 5000 Ada 16 GB。`virtualenv ~/tomas-venv`；`torch 2.1.2+cu121`、numpy/scipy/shapely/joblib、`torch_sparse_solve`（仓库未列入 requirements 的可微稀疏求解依赖）、`pypardiso`（MKL 直接求解，加速均匀化）。

### 3.2 数据生成（论文确切范围 + 并行）

`dataset_py/run_data_generation.py`：按论文规格采样 super-shape（`m∈[1,22]`、`n1,n2,n3∈[0.5,10]` 独立、`a,b∈[0.05,0.75]`，seed=27），shapely 转多边形（裁掉越界形状）→ 算周长/面积 → 150×150 光栅化 → **并行均匀化**。

并行加速：单次 67500 自由度鞍点求解，SuperLU 约 34.5 s → **MKL PARDISO 约 0.57 s（≈60×）**；7000 样本 joblib 32 核并行（每 worker `MKL_NUM_THREADS=1`），**总壁钟约 13–18 min**（论文 MacBook M2 串行 164 min）。

### 3.3 MATLAB → Python 均匀化（核心移植）

`dataset_py/fluid_homogenization.py` 忠实移植 `fluidHomogenization.m`：列主序 `order='F'`、1-based→0-based、标准单元装配三元组（避免 kron 索引技巧）、固定压力基准。验证（无 MATLAB）：Poiseuille C00≈h³/12（恒为 1.018）、转置对称、4 重对称 |C01|/C00≈4e-15。

### 3.4 VAE 训练

`scripts/run_train_vae.py`：12 维属性（8 形状参数 + C00 + C11 + 周长 + 面积），LINEAR×8+LOG×2+LINEAR×2 归一化；17000 epoch、平 LR 8e-3、GPU 约 18 min；保存 `vae_net.pt` + `nomalization.pt`。

### 3.5 多尺度 TO

`scripts/run_to.py`：坐标作为常量输入（detach，每 epoch 重建计算图），Adam + 梯度裁剪 + 罚函数 continuation；支持 `--constraint {PERIMETER,VOLUME}`、`--with-volume`（双约束）、`--fix-latent`（仅取向）、`--seed`、`--init-net`（暖启动）。输出设计图、收敛曲线、速度场、metrics.json、design.npz。真实-FEA 验证 `run_validate_design.py` 用移植的均匀化重算最终设计。

### 3.6 微结构渲染（视觉对齐的关键模块）

`save_microstructures`：每个 super-shape 按**真实轮廓**绘制（不裁剪成方块），尺寸随实心率（√vf，带下限）变化以再现论文的疏密变化，论文配色（pink #F4B6B6 + 黑边 + 浅蓝底 #DAE8FC）。详见 §4。

## 4. 视觉差距分析与对齐（本轮核心）

将复现设计图与论文 Fig 10/11/16 对照，定位到三类问题：

### 问题 1（主因）：渲染器把形状裁成方块、画得太小

旧 `save_microstructures` 用 `np.clip` 把超出单胞的形状**硬裁到方框**，使圆/叶被切成方块；小形状又画得过小、留大空隙 → 整体"点状、稀疏、失真"，与论文"密铺、轮廓清晰"差距明显。

**对齐方法**：重写渲染器——(1) 按**真实轮廓**绘制（无硬裁剪，圆/叶不再被切成方块）；(2) **如实尺寸、不重叠**：用一个**全局缩放**保持各形状的真实相对大小，令第 97 百分位的形状刚好填满单胞（半宽 0.5），极少数更大的封顶——**高渗透（小 vf）胞画得小、周围留出流体（蓝），密实胞紧密相切但不重叠**。论文配色（pink #F4B6B6 + 黑边 + 浅蓝底 #DAE8FC）。

> 注：早期一版渲染器误用 `0.92·√vf/rmax`，使最大形状半径达 0.92 而单胞半宽仅 0.5 → 形状**过大、相互重叠**；已修正为上述全局如实缩放。**仅渲染器一项即让设计图与论文 Fig 11/16 高度接近**（同一份设计数据，重渲前后判若两图）。

### 问题 2：数据采样范围偏离论文

仓库提交的 `datagen.yaml` 用 `m∈[0.5,11]`，而论文为 **`m∈[1,22]`**；复现中途曾把 n 改为相关采样、把 m 收紧到 ≈2（为强行造叶片）——**均偏离论文**。本轮已全部恢复为论文规格（`m∈[1,22]`、`n∈[0.5,10]` 独立）。

### 问题 3：叶/鱼形微结构的来源被误解

一度以为"论文设计里全是叶片"是因为数据里叶片多。实则：论文用宽独立采样，数据里多角星/近圆占多数；**叶/鱼形是最优（强各向异性、低耗散）微结构，由解码器在隐空间导航得到**，优化器因其低耗散而在设计中大量采用。M\* 的 m=0.604 落在采样区间外，正是解码器外推的证据。因此正确做法是"忠实宽数据 + 良好 VAE/优化器 + 正确渲染"，而非人为收窄数据。

### 渲染对齐效果

同一份设计（design.npz）经新渲染器：
- **弯管仅取向**（对标 Fig 11b/d）：全域密铺、尺寸均匀的定向叶片，取向平滑变化形成绕弯流场——与论文几乎一致。
- **分叉管**（对标 Fig 16b）：密实大圆/卵形为壁、定向小透镜/叶片为流道、浅蓝流体透出——与论文几乎一致。

## 5. 结果与论文对比（论文确切范围重训）

按论文规格（`m∈[1,22]`、独立 n）重生成数据 + 重训 VAE + 用新渲染器重跑，真实-FEA 验证：

| 算例 | 本复现 | 论文 | 评价 |
|---|---|---|---|
| §3.4 扩散器最大速度幅值 | **2.783** | 2.81 | 吻合（0.95%）|
| §3.4 扩散器功率（接触面积≈60）| 22.3 | ~25（Fig 14）| 接近 |
| §3.2 弯管仅取向 功率 | 解码 37.8 / **真实 14.15** | 15.1 | 真实吻合（~6%）|
| §3.7 分叉管 功率 | 解码 29.3 / 真实 29.3（0.11%）| 见图 | 验证准，达接触面积 70 |

视觉：弯管仅取向为**密铺定向场**（对标 Fig 11b/d，取向沿弯道平滑变化）；扩散器/分叉管经新渲染器后形态接近论文。

**两点如实记录**：
1. **宽独立数据对 2 维隐空间是强压缩** → VAE 逐样本重构误差约 47%（解码器"中间值"不可靠），**但真实-FEA 验证显示最终设计物理正确**（分叉管 0.11%、弯管真实功率 14.15 吻合 15.1、扩散器最大速度 2.783 吻合 2.81）。这是 2 维隐空间的固有瓶颈，与论文 Table 1 的高精度相比是本复现独立训练 VAE 的局限。
2. **分叉管 varied 设计在高接触面积处出现少量多角星**（论文 Fig 16b 为圆/叶），属宽数据 + 2 维 VAE 的副产物。若要最干净的"叶/圆主导"外观（最贴 Fig 16b），可用**收窄的叶片库**（m≈2、相关 n，见复现文档 §5.9），代价是接触面积上限较低、个别功率偏离——这是"忠实数据规格"与"最干净叶片外观"之间的权衡。

## 6. 结论

- **视觉差距的主因是渲染**：按真实轮廓 + √vf 尺寸 + 论文配色重写渲染器后，设计图与论文 Fig 11/16 高度一致。
- **数据采样应忠实论文**（m∈[1,22]、独立 n）；叶/鱼形由解码器导航产生，无需人为收窄数据。
- 理论与实现链条完整：super-shape 参数化 → 周期均匀化（MATLAB→Python 并行）→ VAE 可微隐空间 → 坐标网络多尺度 Stokes TO → 真实-FEA 验证 → 论文级可视化。
